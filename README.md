# Малина

Воксельная игра в духе Minecraft Dungeons: изометрическая камера, огород, жуки.
Написана на TypeScript (строгий режим) и three.js, собирается Vite.

## Как играть
- **WASD** — ходить, мышь — прицел, колесо — приблизить/отдалить
- **ЛКМ / Пробел** — огонь (держи кнопку)
- **Q / ПКМ** — мод ствола (второй режим стрельбы)
- **1–8** — сменить ствол
- **E** у грядки — посадить куст (5 ягод) или собрать урожай
- **E** у лавки — стволы, улучшения и патроны (только днём)
- **M** — звук, **Esc** — пауза

### Ягоды и патроны
Сейчас для тестов игра начинается с 1000 ягод — поменять можно в `src/config.ts` (`START_BERRIES`, обычное значение 30).

Ягоды — валюта: посадка кустов, покупка стволов, улучшения (до 5 звёзд, +20% урона и короче перезарядка мода) и патроны в лавке.
Патроны четырёх видов: пули, дробь, энергия и гранаты. Из убитых жуков выпадают коробки с патронами и аптечки — они сами притягиваются к герою.
Пули понемногу копятся сами до 60, чтобы автомат не замолкал насовсем.
Пули и дробь, попавшие в стены поля, деревья, камни, домик, прилавок или фонари, в 50% случаев рикошетят (`RICOCHET_CHANCE` в `src/config.ts`): отлетают под случайным углом с половинным уроном и ещё могут задеть жука.

### День и ночь
Днём малина растёт и работает торговец. Ночью рост замирает и с разных сторон приходят жуки:
- обычные, быстрые рыжие и большие фиолетовые носороги ползут к кустам и кусают героя вблизи;
- **плевуны** (зелёные) — быстрые, держат дистанцию и плюются кислотой;
- **бомбардиры** (рыжие с огненным мешком) — ещё быстрее, бьют очередью из трёх горячих капель.

Стрелки целятся в героя, если он рядом, а иначе — в кусты. Если здоровье кончится, герой очнётся у домика через 5 секунд.
На рассвете оставшиеся жуки зарываются в землю. Игра заканчивается, когда все кусты съедены, а ягод на новый куст не хватает.

## Плейграунд разработчика (этап 0)
Служебная сцена для настройки передвижения и стрельбы: шахматный пол 48 × 48 м, стены, укрытия 0,9 и 2 м, колонна, угол, коридор с проёмом, стена под 45°, стрельбище с мишенями на 5–30 м, подвижная мишень и манекен-стрелок.

Открыть: `dist/index.html?dev=playground` (или `http://localhost:5173/?dev=playground`), либо **F9** в главном меню. В сборке для игроков выключается так: `VITE_DEV_TOOLS=off npm run build`.

- **WASD** — ходьба, **Shift** — бег, **ПКМ** — прицел, **C** — присед, **Space** — перекат, **R** — перезарядка, **1 / 2** — основной ствол / ПМ, **T** — сменить основной (АК-74 → AR-15 → двустволка)
- **F1** — панель параметров (ползунки, «Скопировать JSON», «Сбросить»), **F2** — коллайдеры, **F3** — луч и конус разброса, **F4** — телеметрия, **F5** — бесконечные патроны, **F6** — бессмертие, **F7** — время 1 / 0,5 / 0,25 / 0,1, **P** — пауза, **.** — кадр вперёд, **F8** — FPS, **B** — bloom, **N** — сброс мишеней
- **Загон врагов** (за нулевой точкой): 5 жуков и 3 арахнида стоят в строю и спят. Попадание или пуля рядом будит именно этого врага; **N** — сбросить мишени и вернуть всех врагов на места, **Ctrl+0** — заморозить ИИ
- **Тюремщики** (пост ЧВК у угла комнаты): бойцы в чёрной форме и балаклавах, утащили малину — пока спят, едят её. **Стрелок** (AR-15) прячется за укрытиями, выглядывает и бьёт очередями, перезаряжается в укрытии; **Двустволка** перебегает ближе и вблизи бьёт дуплетом; **Огнемётчик** идёт напролом и поджигает, а баллоны у него на спине взрываются от попаданий сзади и сбоку. Разбуженный поднимает тревогу на весь пост. Присевший за низким укрытием герой для их пуль недосягаем
- **Арахниды** (как в «Звёздном десанте», полосы светятся): **Воин** — ближний бой, заходит с фланга, бьёт и отскакивает; **Ткач** — держит дистанцию и плюётся ядовитой паутиной (замедляет и травит); **Прыгун** — прыгает прямо на героя на 3 длины тела, после прыжка ненадолго оглушён. Все трое замечают, что на них навели ствол, и отпрыгивают с линии огня; прыгают только по свободной прямой — не через стены и укрытия, обходят их по навигационной сетке

Все настраиваемые числа — в `src/tuning.ts`.

Тесты (Playwright, нужен собранный `dist`): `npm run build && npx playwright install chromium && npm test`.

## Запуск
Без установки: открыть `dist/index.html` в браузере.

Для разработки:
```
npm install
npm run dev      # http://localhost:5173
npm run typecheck  # проверка типов
npm run build    # проверка типов + сборка dist/index.html одним файлом
```

## Устройство кода
- `src/config.ts` — баланс: урожай, длина дня и ночи, здоровье; общие типы
- `src/world.ts` — карта из блоков, домик, деревья, фонари, светлячки
- `src/player.ts`, `src/beetle.ts`, `src/bush.ts` — герой, жуки, кусты
- `src/fx.ts` — частицы, дульные вспышки, гильзы, взрывы, цифры урона
- `src/main.ts` — точка входа: игра или плейграунд
- `src/game.ts` — игровой цикл, бой, ночи, интерфейс (режим фермы)
- `src/tuning.ts` — настраиваемые числа: скорости, выносливость, стволы
- `src/hero.ts` — боец: модель с суставами, тактическое передвижение, процедурная анимация
- `src/firearms.ts`, `src/gunplay.ts` — реальные стволы, магазины, перезарядка, разброс, рикошеты
- `src/collision.ts` — препятствия, скольжение вдоль стен, лучи пуль
- `src/jailer.ts`, `src/cover.ts` — тюремщики (ИИ управляет тем же бойцом, что и игрок) и точки укрытий
- `src/arachnid.ts` — арахниды: модель, ноги на IK, ИИ (уклоны, фланг, паутина, прыжок)
- `src/nav.ts` — навигационная сетка: путь в обход стен, проверка прыжков
- `src/ik.ts` — двухзвенная IK для рук и ног
- `src/dev/` — плейграунд разработчика: сцена, мишени, панель, оверлеи
- `src/weapons.ts` — стволы, патроны, моды, улучшения и модели
- `src/combat.ts` — стрельба, снаряды, моды, взрывы, плевки жуков, трофеи
- `src/daynight.ts` — смена дня и ночи, свет и небо
- `src/shop.ts` — окно лавки
- `src/textures.ts`, `src/icons.ts` — пиксельные текстуры и иконки рисуются кодом
- `src/audio.ts` — звуки синтезируются через Web Audio
