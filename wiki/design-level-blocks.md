# Блоки уровней и редактор

Версия 1.1 от 22.10.2026. Опирается на `claude/adr-003-visual-style.md` (стиль Minecraft Dungeons) и `claude/design-dungeon.md` (комнаты как тайлы).

## 1. Решение

Мир собирается из воксельной сетки и редактируется в редакторе уровней. Старый `world.ts` с процедурным огородом, который сыпал кубы прямо в `InstancedMesh`, заменён на три слоя:

- **данные** — `src/level/level.ts`: чанки 16³, в клетке индекс блока и поворот; карты хранятся в **JSON** (`assets/maps/*.json`);
- **палитра и формы** — `src/level/palette.ts` + **`.obj`‑файлы** `assets/blocks/*.obj`: блок = форма + текстуры в её слотах + правила столкновения;
- **рендер и столкновения** — `src/level/mesher.ts` (гибридный мешер чанков) и `src/level/collide.ts` (высотные столкновения).

Полноценный воксельный движок (greedy meshing, LOD) не нужен: уровни размером с референсы — 20–60 тыс. блоков, это 10–30 draw call’ов. Переписана модель данных и столкновения, а не рендер ради рендера.

## 2. Соглашения

| Что | Правило |
|---|---|
| Размер | 1 блок = 1 м. Формы на решётке **1/16**: полублок 8/16, столб забора 4/16, стенка 8/16, факел 2/16 |
| Клетка | `(x, y, z)` стоит **центром на целых x, z** и занимает `[x−0,5; x+0,5) × [y; y+1) × [z−0,5; z+0,5)`. Поверхность огорода — верх клеток `y = −1`, герой стоит на `y = 0` |
| Поворот | `rot` 0–3 — четверти оборота вокруг Y; `rot = 1` переводит +X в +Z |
| Текстуры | 16 × 16, пиксельные, генерируются кодом (`textures.ts`), складываются в атлас со слотами 32 × 32 и полями из растянутых краёв (мипы не подмешивают соседей) |
| Имена блоков | Карты ссылаются на блоки по имени из палитры — имена **не переименовывать**, только добавлять |
| Высота столкновения | `collide` в палитре: 0 — проходимый (трава, вода), 0,5 — полублок и ступени, 1 — куб, 1,5 — забор и стенка (не перешагнуть) |
| Шаг героя | 0,5 м — на полублок и ступень поднимается сам, выше — стена; с обрыва падает |

## 3. Формат карты (JSON)

```json
{
  "format": "malina-level", "version": 1, "name": "Огород",
  "palette": ["air", "grass", "dirt", "…"],
  "rows": [[y, z, [[x0, длина, индексБлока, поворот], …]], …],
  "entities": [],
  "spawn": [0, 0, 2]
}
```

Ряды вдоль X с пробегами одинаковых блоков: огород (9,4 тыс. блоков) — 52 КБ. `entities` зарезервировано под точки появления, фонари и предметы. Карты из `assets/maps/` вшиваются в сборку (`import.meta.glob`), один файл `dist/index.html` сохраняется.

## 4. Формы блоков (.obj)

`assets/blocks/<имя>.obj`, куб 0..1, нужны только `v / vt / vn / usemtl / f`. `usemtl` — **слот текстуры** (`top`, `side`, `bottom`, …), палитра решает, какая текстура в слоте. UV в долях блока, поэтому пиксели сходятся по сетке и грань полублока берёт нижнюю половину текстуры. Грань, лежащая на границе куба, помечается направлением и прячется, если сосед непрозрачный.

Формы генерирует `scripts/gen-blocks.mjs` (`npm run blocks`), но файлы можно рисовать руками (Blockbench, Blender) — главное, соблюдать куб 0..1 и слоты.

| Форма | Что это |
|---|---|
| `cube`, `cube_x` | куб; куб с «торцами» на ±X (бревно лёжа) |
| `slab`, `stairs`, `layer` | полублок; ступени (поднимаются к +X, вращаются); тонкий слой 2/16 |
| `wall_post` + `wall_seg` | стенка 8/16: столбик и сегменты к соседям (автосоединение) |
| `fence_post` + `fence_rail` | забор: столб и две перекладины к соседям |
| `water` | куб высотой 14/16, грани между водой не рисуются |
| `cross`, `fire`, `torch`, `torch_flame`, `campfire_logs`, `campfire_fire` | крест из двух плоскостей (трава, цветы, огонь); факел; костёр |
| `rail`, `crate` | бортик грядки по краю клетки; ящик чуть меньше куба |

## 5. Палитра (что уже есть)

**Земля:** трава, земля, тропинка, гравий, песок, грядка, **вода** (анимированный сдвиг UV, полупрозрачная), **кислота** (светится), **нора жуков**.
**Камень:** камень, булыжник, булыжник мшистый, **каменный кирпич** (+ мшистый, треснутый, руинный с мешаными вариантами), **плиты мостовой** — у каждого куб + ступени + полублок, у камней ещё стенка; **низкое укрытие** 14/16 из кирпича и булыжника.
**Дерево:** бревно (стоя и лёжа), доски светлые и тёмные (+ ступени, полублок), **забор**, **ящик**, бортик грядки, черепица красная и тёмная (ступени, полублок), сено.
**Растения:** **листва** (куб с дырявой текстурой — крона не читается как кубы, грани между листвой не прячутся), куст с ягодами, трава высокая, папоротник, 4 цветка (случайный поворот, сдвиг и размер в клетке).
**Свет:** факел, костёр, огонь (3 кадра, светится под bloom). 8 ближайших к камере источников — настоящие `PointLight` с мерцанием, остальные только светятся.

Из референсов ещё не сделано (следующие): дверь и окно, люк, лоза на стенах, флаг и гирлянда флажков, тент, колодец, настенный факел, «забор на каменном основании» (собирается из `cobble_wall` + `fence` слоями, отдельный блок не нужен).

## 6. Рендер

На чанк 16³ — по одной сетке на слой: `opaque` и `cutout` (атлас, Lambert, тени), `water` (своя текстура, прозрачная), `fire` (своя текстура, `MeshBasic`, не tone‑mapped → bloom). Граница между непрозрачными соседями не рисуется; на гранях кубов — вершинное затенение углов (AO по трём соседям); яркость гуляет от блока к блоку (`jitter`). Чанк перестраивается при правке (`level.dirty` → `renderer.sync()`).

## 7. Столкновения с высотой

`collide.ts`: тело — цилиндр (r 0,35, h 1,6) на высоте ног. `resolve` выталкивает из клеток, чей верх выше ног + 0,5; `floorAt` — пол под точкой (самый высокий блок не выше ног + 0,5); `wallHit` — где отрезок пули упирается в блок и нормаль грани. Герой (`player.ts`) получил `pos.y`, гравитацию и шаг.

**Жуки** (`beetle.ts`, `BeetleWorld`): тот же `resolve` и `floorAt`, а путь в обход стен — `NavGrid` из `obstaclesOf(level, 0, …)` (клетки с верхом выше 0,5, слитые в полосы вдоль X) плюс пропсы (лавка, фонари). Раз в 0,4 с жук проверяет прямую к цели и, если она закрыта, берёт следующую точку A*. Пули (`combat.ts`) отскакивают от стен из блоков через `terrain.wallHit`. Тюремщики и арахниды живут в плейграунде без уровня — им высота ещё не нужна.

## 8. Редактор

`?dev=editor` (F10 в меню), `src/dev/editor.ts`. Орбитальная камера (СКМ/ПКМ/колесо, WASD), рейкаст по вокселям (DDA), ставить/убирать, заливка и вырезание параллелепипеда, пипетка, поворот, срез по высоте, точка появления, отмена/повтор, палитра с превью текстур, встроенные карты, загрузка/скачивание JSON, автосохранение в localStorage, кнопка «Играть» (`?map=editor`). Трава и цветы помечены `replaceable` — новый блок встаёт на их место.

## 9. Комнаты подземелья и этаж

Заготовки — ASCII в `src/level/rooms.ts` по легенде design‑doc: `#` стена, `.` пол, `o` колонна, `=` низкое укрытие (блок 14/16 — не перешагнуть, стоя стрелять поверх можно), `~` кислота, `n` нора, `c` сундук, `D` дверь (проём 3 клетки по центру каждой стороны), `T` факел, `S` спавн, `M` торговец, `A` алтарь, `B` босс. `validateRoom` проверяет рамку и двери; `roomFromTemplate` строит `Level`: пол из плит с вкраплениями булыжника и мха, стены из кирпича 3 блока (со стороны камеры, +X и +Z, — 1 блок), двери и предметы — в `entities`, тип и размер — в `meta.room`. `npm run map:rooms` → `assets/maps/rooms/*.json`; эти JSON можно открыть и править в редакторе — генератор берёт их, а не ASCII.

Сейчас 10 заготовок: start, 4 боевые (pillars, acid, hall 24 × 16, cross), elite, storage, merchant, altar, boss.

Генератор этажа `src/level/dungeon.ts`, детерминирован от seed: сетка 5 × 5, шаг 32 м; `layoutFloor` — главный путь случайным блужданием 5–6 комнат (последняя босс), 1–2 ответвления из элитной, торговца (обязателен на этажах 2–3) или кладовой и алтаря; `buildFloor` ставит комнаты по центрам ячеек (центр ячейки — на середине двери, поэтому коридоры между соседями прямые), закладывает лишние двери кирпичом, прокладывает коридоры 3 клетки шириной со стенами и факелами, собирает `entities` с типом комнаты и ячейкой, `spawn` из стартовой. Посмотреть: кнопка «Этаж…» в редакторе или `?map=dungeon&seed=N&floor=K` в игре (пока это хаб‑режим на чужой карте — режим подземелья с волнами и дверями впереди).

## 10. Файлы и команды

```
assets/blocks/*.obj        формы            npm run blocks     (scripts/gen-blocks.mjs)
assets/maps/garden.json    огород           npm run map:garden (scripts/export-map.ts, Node ≥ 22.18)
assets/maps/rooms/*.json   комнаты          npm run map:rooms
src/level/{level,palette,obj,shapes,atlas,mesher,collide,garden,rooms,dungeon,maps}.ts
src/dev/editor.ts, editor.css
```

Что осталось от старого `world.ts`: фонари, лавка торговца, светлячки и круглые коллайдеры для пуль (деревья, домик, камни) — пропсы поверх сетки.
