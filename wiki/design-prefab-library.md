# Библиотека пресетов: готовые куски мира для сборки уровней

Версия 1.4 от 29.10.2026. Источник — [sources/refs-settlements.md](sources/refs-settlements.md) (17 скриншотов Elden Ring и Minecraft Dungeons). Блоки и декор как механизм — [design-level-blocks.md](design-level-blocks.md), [design-level-decor.md](design-level-decor.md); редактор — [design-editor.md](design-editor.md) (раздел 6); наборы по миру MCD — [style-world.md](style-world.md); гамма — [style-terrain.md](style-terrain.md).

## 1. Зачем

Уровни — открытые холмистые местности с небольшими поселениями на пути. В движке мир хранится блоками, но **собирать уровень блоками нельзя** — слишком долго. Собираем из **пресетов**: готовых кусков (блоки + декор + свет), которые кладутся в редакторе кликом, поворачиваются и комбинируются. Квадратный мир оживляют **мелкие детали** — пни, камни, горшки, бочки, свечи, кости, цветы, — поэтому каждый пресет несёт свой декор, голых коробок в библиотеке нет.

Сборки `kit.ts` остаются («поставь холм в эту точку» — процедурно, по месту), библиотека — это **запечённые** пресеты: один раз сгенерированы кодом, лежат в репозитории как JSON, одинаковы на любой карте.

## 2. Формат и где лежит

| Что | Где |
|---|---|
| Тип | `LibraryPrefab` (`src/level/prefab-lib/types.ts`): `id`, `title`, `category`, `hint`, `size: [w, h, d]`, `seed`, `cells: [dx, dy, dz, блок, поворот][]`, `decor: DecorItem[]`, `entities: LevelEntity[]` — всё относительно **опорной клетки** (низ, центр) |
| Строители | `src/level/prefab-lib/builders.ts`: `Builder { id, title, category, hint, build(c) }`; `c.L` — локальная `Level` с опорой в (0, 0, 0), `c.dec(name, x, y, z, rot?, on?)` — декор, `c.light(kind, x, y, z, data?)` — свет, `c.rnd()` — детерминированный случай от `seed`; сборки `kit.ts` вызываются с этой же `L` |
| Запекание | `bake(builder, seed)` (`src/level/prefab-lib/build.ts`) → `LibraryPrefab`; `npm run prefabs` (`scripts/gen-prefabs.ts`) пишет `assets/prefabs/<id>.json` и витрину `assets/maps/prefabs.json` |
| В сборке | `src/level/prefab-lib/index.ts`: `LIBRARY` — все JSON через `import.meta.glob`, `LIBRARY_CATEGORIES` |
| Постановка | `stampPrefab(L, p, x, y, z, quarter)` (`src/level/prefab-lib/stamp.ts`): клетки через `L.set` (в редакторе — одна правка в отмене), возвращает декор и свет со сдвигом; **поворот** `quarter` 0–3: клетки `(dx, dz) → (−dz, dx)`, у поворачиваемых блоков `rot + 1`, у декора рыск + 90° (рыск — внешний поворот, `YXZ`, наклон и крен сохраняются), у света — `rot + 90` |
| В редакторе | вкладка **«Библиотека»** панели префабов (разделы — категории каталога), превью, режим «Поставить»: **R** — повернуть на 90°, ЛКМ — поставить. Свой префаб из выделения → ПКМ → **«Сохранить в библиотеку (JSON)»** — скачивается в том же формате, кладётся в `assets/prefabs/` |
| Витрина | `?map=prefabs` — все пресеты сеткой, по категории — ряд, подпись на полу (`src/level/prefabs-map.ts`); для ревью «похоже ли на референс» и для теста |
| Тест | `tests/prefabs.spec.ts`: витрина без ошибок, число пресетов = число JSON, у каждого есть декор, поворот не теряет клетки, постановка в редакторе с поворотом и отмена |

Общие строители в `builders.ts`, `builders-ruins.ts` и `builders-settlement.ts`: `goldenTree`, `pineTree` (деревья для пресетов и рощи), `flagRoad` / `dirtRoad` (дорога шириной 3 по центральной линии, обочина рваная), `inBlob` (эллипс с рваным краем для пруда); руины — `pillar` (столб с рваным верхом, у земли мшистый и треснутый кирпич), `wallRun` (стена с гуляющей высотой), `arch`, `ruinFloor` (плиты с дырами и травой), `onWall(name, x, y, z, face)` — настенный декор на грани клетки с правильным рыском и опорой `on`; поселение — `walls(x0, z0, x1, z1, h, блок, дверь, окна)`, `gableX` (конёк вдоль X: ступени по скатам, полублок на коньке), `hipRoof` (кольца ступеней наружу), `fenceRun` (забор с пропусками); композиции — `use(c, id, x, z, quarter, seed?)` вкладывает средний пресет по id строителя, `dirtRoadX`, `sprinkle` (мелочи только на свободные клетки), `grassBits` (пучки по траве).

Правила:
- **Опора** — низ-центр: `y` — первый слой воздуха над землёй в точке клика; клетки с `dy < 0` врезаются в землю (русло, фундамент).
- **Варианты** — один строитель, несколько `seed` (`variants` у строителя): деревня не выглядит копипастой. Файлы `<id>.json`, `<id>_2.json`, …
- **Масштаб:** мелкий (≤ 3 м, деталь), средний (4–10 м, постройка), крупный (10–24 м, композиция). Крупные собираются из средних строителей — код не дублируется.
- **Живость:** на 8 × 8 м пресета — 4–6 мелких предметов; у каждой постройки — минимум бочка / ящик / фонарь у входа; у руины — щебень, горшки, трава в швах.
- Новая поверхность — в гамме [style-terrain.md](style-terrain.md): `softFill`, пятна, не шум.

## 4. Партии

1. **Инфраструктура** — формат, генератор, поворот, вкладка, витрина, тест; 4 пробных пресета (`hay_stack`, `tree_oak`, `wall_stepped`, `campfire_camp`) — **сделано 29.10.2026**.
2. **Дорога и природа** — A + B целиком (20 строителей, 45 пресетов с вариантами); блоки `leaves_gold`, `flower_orange`, `tiles_broken`; декор `tree_dead`, `reeds`, `stump`, `rock_small`, `leaf_litter`; витрина переносит длинные ряды — **сделано 29.10.2026**.
3. **Руины** — C целиком (11 строителей, 22 пресета, `builders-ruins.ts`); блоки `bricks_old_stairs` / `_slab` / `_wall`; декор «руины» — надгробия трёх форм, крест, статуя, чаша, горшки, плющ, череп; помощники `pillar`, `wallRun`, `arch`, `ruinFloor`, `onWall` (настенный декор на грани клетки) — **сделано 29.10.2026**.
4. **Поселение** — D целиком кроме `goat_pen` (17 строителей, 34 пресета, `builders-settlement.ts`); блоки `crops`, `roof_thatch`, `shingles`; 14 предметов декора; помощники `walls` (коробка с дверью и окнами), `gableX` (двускатная крыша), `hipRoof` (шатровая), `fenceRun` — **сделано 29.10.2026**.
5. **Композиции** — E целиком (5 строителей, 10 пресетов, `builders-compositions.ts`): средний пресет запекается своим строителем и вкладывается со сдвигом и поворотом (`stampInto` в `build.ts`, `c.put` / `c.putEntity` для готового декора и света) — код построек не дублируется, JSON средних пресетов не меняется — **сделано 29.10.2026**.

Каждая партия: строители → `npm run prefabs` → витрина → сборка → целевой тест.
